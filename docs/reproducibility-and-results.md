# Reproducing and reviewing the observed results

## What was run

Project owner used a Snowflake trial account in November 2026. The eight-case smoke test ran the standard `AI_SENTIMENT`, `AI_EXTRACT`, and `AI_CLASSIFY` pipeline and opened the Streamlit dashboard. The 24- and 200-case exercises use `AI_CLASSIFY` for a **different outcome: explicit issue-resolution evidence**.

The following artifacts are **observed model responses**, provided by the owner after actual Snowflake execution:
- `data/cortex_smoke_observed.csv` (8 records, flattened)
- `data/resolution_v2_observed.csv` (24 records, case-level)
- `data/resolution_v3_observed.csv` (200 records, case-level with raw JSON)

SQL inputs:
- `sql/00_setup.sql`, `sql/01_quickstart_seed.sql`, `sql/02_enrich.sql`, `sql/03_views.sql`
- `sql/07_resolution_v2_seed.sql`, `sql/08_resolution_v2_run.sql`
- **`sql/09_resolution_v3_200_benchmark.sql`** — standalone 200-case v3 benchmark, create/seed/infer/view/report

## How to inspect results offline

Open the CSV files in a spreadsheet or use Python:

```python
import csv
from collections import Counter

with open("data/resolution_v3_observed.csv", newline="", encoding="utf-8") as f:
    records = list(csv.DictReader(f))

print("Cases:", len(records))
print("Reference balance:", Counter(r["GOLD_RESOLUTION"] for r in records))
print("Predictions returned:", sum(bool(r["CORTEX_RESOLUTION"]) for r in records))
print("Exact matches:", sum(r["GOLD_RESOLUTION"] == r["CORTEX_RESOLUTION"] for r in records))
print("Mismatch IDs:", [r["CASE_ID"] for r in records if r["GOLD_RESOLUTION"] != r["CORTEX_RESOLUTION"]])
```

This reproduces **200 cases, 200 returned predictions, 200 matches** from the exported rows, without triggering inference.

## Limitations and bias

- These are purpose-built **synthetic** utterances; the v3 sample is 20 sentence patterns × 10 product substitutions. Examples are highly correlated.
- Labels were generated by design and were not assigned by independent annotators; high agreement is expected for direct lexical resolution cues.
- The v2 and v3 sample composition *and* the model task instructions differed; one cannot attribute the difference (83.33% to 100%) to prompt changes alone.
- `GOLD_DISSATISFACTION` in the synthetic test data was not evaluated by the v3 classifier. **No dissatisfaction accuracy can be inferred** from the v3 resolution match rate.
- The separate BIRD research dataset is not redistributed here and no direct BIRD-vs-Cortex comparative benchmark has been established.
- The eight-case dashboard screenshot shows the app *before* the resolution-v3 dataset, so it must not be presented as a 200-case dashboard screenshot.
- This account's trial is time-limited. Neither future availability nor credit cost, latency, query IDs, and precise model internals were captured in the shared artifacts.

## Re-running with a Snowflake account

Use an authorized role, create or select the demo DB/schema/warehouse, review the latest function signature in Snowflake docs, then run `sql/09_resolution_v3_200_benchmark.sql` as a worksheet **Run All**. `AI_CLASSIFY` inference incurs charges. Existing complete v3 responses are skipped by a version+case guard. If you change the task or descriptions, create a new version and output table/view or update the version string without overwriting old observed results.

Export full predictions, raw `VARIANT` responses and timestamps as CSV; record query IDs, Snowflake region, role, execution date, and available consumption data separately. Never use real customer transcripts without authorization and privacy controls.

## Evaluation for a future paper

Pre-register resolution ontology and tie-breaking rules. Use disjoint naturally worded and multi-turn cases, independent annotators with agreement checks, a reproducible baseline, classwise metrics (including confusion matrix), confidence intervals and transparent costs. Report whether inference used single utterances or full conversation histories. These are future validation requirements, **not achievements of the current benchmark**.
